Sumber data bisnis

Data bisnis baru diambil dari Google Maps melalui ekstensi Chrome yang dimulai pengguna. Ekstensi tidak memerlukan Google Cloud atau Places API key.

Unduh JSON hasil ekstensi lalu impor melalui menu Impor hasil Google Maps. Sistem menyimpan data, URL profil, dan waktu pengambilan ke riwayat; hasil dapat diarsipkan dan diekspor ke Excel.

Telepon, website, rating, dan jumlah ulasan disimpan sesuai yang terbaca dari Google Maps. Nomor seluler tidak menjamin akun WhatsApp aktif.

Klik Mulai scraping pada ekstensi untuk mengumpulkan hasil pencarian, maksimal 100 per sesi. Proses dapat dihentikan dan berhenti saat halaman dibatasi. Tidak ada bypass CAPTCHA.

Gemini Pro dan Google Maps Platform memiliki layanan dan kuota terpisah. Key Gemini tidak membuka akses Places API.
